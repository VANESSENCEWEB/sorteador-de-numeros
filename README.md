O **Sorteador PRO** é uma ferramenta de alta performance para geração de números aleatórios, construída com foco em uma experiência de utilizador (UX) moderna e técnica. Inspirado em dashboards de gestão de dados, o projeto utiliza uma interface baseada em **Glassmorphism**, tipografia técnica e lógica robusta de sorteio.

## 🚀 Funcionalidades

-   **Configuração Dinâmica:** Defina a quantidade de números, o valor mínimo e o valor máximo.
-   **Lógica Anti-Repetição:** Algoritmo otimizado que valida se o intervalo permite números únicos antes de executar.
-   **Output Estilo Terminal:** Os resultados são renderizados com animações de cascata (delay progressivo).
-   **Design de Elite:** Tipografia baseada em *JetBrains Mono* para dados e *Space Grotesk* para interface.
-   **Totalmente Responsivo:** Layout adaptável para smartphones, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando tecnologias nativas para garantir máxima velocidade:

-   **HTML5 Semântico:** Estrutura organizada por módulos (Config e Output).
-   **CSS3 Custom Properties:** -   Uso intensivo de variáveis para o tema Neon.
    -   Efeitos de `backdrop-filter` para transparências reais.
    -   Grid Layout para separação de painéis.
-   **Vanilla JavaScript (ES6+):** -   Motor de sorteio baseado em `Math.random()`.
    -   Gestão de estados para logs de erro e validação de input.
